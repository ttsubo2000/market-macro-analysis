## エグゼクティブサマリー

**前回レポート（2026-06-13）以降、日銀は6月に追加利上げを実施し、政策金利は0.727%から0.841%へ引き上げられた**。一方でコアCPIは1.4%で2ヶ月連続横ばいとなり、急落局面は一旦止まったものの目標（2%）への回復には至っていない。最大の変化はBEI（期待インフレ率）で、6月下旬にかけて2.09%前後から1.97%台へ急落し、**前回レポートで指摘した「市場の楽観」がここへ来て後退し、2%の物価目標を下回った**。

これは「コアCPIとBEIの乖離」というテーマの決着の付き方として、CPIがBEIに追いついたのではなく、**BEIがCPI側に収斂する形で乖離が縮小した**ことを意味する。株高（日経225は3ヶ月で+21%、72,000円台の高値を記録）と円安（161円台）という外部環境の追い風は続いているが、期待インフレの後退は日銀の正常化路線に慎重さを迫る材料になり得る。テイラールール適正金利（1.85%）との乖離は1.01%ポイントまで縮小したものの、依然として緩和的な状態が続いている。

### 1-2. テイラールール：適正政策金利の試算

```
【テイラールール】
適正金利 ＝ 均衡実質金利 ＋ 目標インフレ率 ＋ 0.5 × 需給ギャップ ＋ 1.5 × インフレギャップ

均衡実質金利（自然利子率）: 0.5%（日銀リサーチ推計レンジ中央値）
目標インフレ率: 2.0%
需給ギャップ: +0.5%
インフレギャップ（コアCPI − 2%）: 1.4% − 2.0% ＝ −0.6%

適正金利 ＝ 0.5 ＋ 2.0 ＋ 0.5 × 0.5 ＋ 1.5 × (−0.6)
         ＝ 0.5 ＋ 2.0 ＋ 0.25 − 0.9
         ＝ 1.85%
```

| 項目 | 値 |
|------|---|
| テイラールール適正金利 | **1.85%** |
| 現在の政策金利 | 0.841% |
| 乖離（過剰緩和幅） | **−1.01%pt**（前回 −1.12%pt） |

コアCPIと需給ギャップの値が前回レポートと同一のため試算上の適正金利は1.85%で変わらないが、6月の利上げにより実際の政策金利との乖離は1.12%ポイントから1.01%ポイントへわずかに縮小した。それでも1%ポイント程度の開きが残っており、ルールベースで見れば追加利上げの余地は依然として大きい。

#### ⑤ 政策金利・実質金利・自然利子率（金融ブロック）

![政策金利・実質金利（金融ブロック）](./images/policy_rate_chart.png)

```
実質金利 ＝ 政策金利（0.841%）− BEI（1.973%）＝ −1.13%
自然利子率（中立基準）＝ 0.5%
緩和超過幅 ＝ −1.13% − 0.5% ＝ −1.63%ポイント
```

実質金利は前回の−1.45%から−1.13%へ縮小したが、依然として自然利子率を1.6%ポイント以上下回っており、金融環境は**大幅に緩和的**な状態が続く。名目金利の引き上げ幅（+0.11%pt）よりもBEIの低下幅（−0.20%pt程度）の方が大きく寄与しており、実質金利の縮小は「利上げ」と「期待インフレの後退」の両方が組み合わさった結果である点に注意したい。

## 3. 総合考察（金融政策への含意）

### 3-1. 現状の総括：「収斂した乖離」と「残る乖離」

前回レポートで指摘した2つの乖離は、この1ヶ月でそれぞれ異なる動きを見せた。

**乖離①：コアCPI（1.4%）とBEI（1.97%）の差 → 0.57%ポイント（前回0.77%pt から縮小）**

縮小の中身は「BEIの後退」であり、CPIの回復による収斂ではない。市場の期待インフレが目標割れした事実は、前回懸念していた「市場の楽観が過剰」というリスクシナリオがある程度顕在化したことを意味する。

**乖離②：テイラールール適正金利（1.85%）と政策金利（0.84%）の差 → 1.01%ポイント（前回1.12%ptから縮小）**

6月の利上げにより縮小したが、依然として1%ポイント程度の差が残る。ルールベースで見れば利上げ余地はまだ大きいが、BEIの後退はこの正当化根拠をやや弱める材料となる。

### 3-2. 次回MPMに向けたシナリオ分析

**シナリオA：利上げ継続（確率: 低〜中）**

需給ギャップ+0.5%、株高継続という「実体経済の底堅さ」を根拠に追加利上げに踏み切るシナリオ。ただしBEIの後退という新たな向かい風があり、6月時点より確率はやや低下したとみられる。

**シナリオB：様子見（確率: 高）**

コアCPIが1.4%で横ばい、BEIも目標を割り込むなか、6月に利上げしたばかりであることも踏まえ、次回は効果見極めのため様子見を選択するシナリオ。実質金利は依然マイナス圏で緩和的環境は継続する。

**シナリオC：利上げ停止・緩和方向の点検（確率: 低〜中）**

BEIの低下がさらに進み、コアCPIも反発しないまま推移した場合、「期待インフレの定着に黄信号」として正常化路線の一時停止が意識されるシナリオ。前回レポート時点よりもこのシナリオの現実味はやや増している。

### 3-3. リスクシナリオ

**上振れリスク（物価加速・利上げ前倒し）**

- 円安が162円を超えて定着 → 輸入インフレが再燃
- 6月分以降のコアCPIが反発 → BEIの下げ止まり・再上昇
- 日経225の上昇が賃上げ機運を後押し → 好循環の再確認
- → 日銀は追加利上げを継続し、年内に政策金利が1.0%へ接近する可能性

**下振れリスク（期待インフレ低下・正常化頓挫）**

- BEIの低下が加速し、1.9%を割り込む水準へ
- コアCPIが1.4%からさらに下振れ
- 円安一服・米金利低下観測 → 円高圧力再燃 → 輸入物価下落
- → 日銀は次回以降の利上げを見送り、正常化ペースの再検討を迫られる

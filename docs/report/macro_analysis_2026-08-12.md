## エグゼクティブサマリー

**前回レポート（2026-07-11）以降、コアCPIが3ヶ月ぶりに反発した**。2026年6月分は1.6%となり、4月・5月の1.4%横ばいから0.2%ポイント上昇した。前回レポートで最大の懸念だったBEI（期待インフレ率）は7月中旬に1.883%まで下げたあと月末にかけて1.95%前後まで戻し、**下げ止まりを確認**した。結果として「コアCPIとBEIの乖離」は0.57%ポイントから0.35%ポイントへ縮小したが、**今回はBEIの後退ではなくCPIの回復が主因**であり、前回の悲観的な収斂とは中身が逆転している。

日銀は7月も追加利上げを実施し、政策金利は0.841%から**0.978%**へ。6月に続く2ヶ月連続の引き上げで、1%の大台が目前に迫った。ただしCPIが上向いたことでテイラールール適正金利も1.85%→**2.15%**へ切り上がり、**利上げしたにもかかわらず乖離は1.01%ポイントから1.17%ポイントへ拡大**している。

新たな変化は為替で、円は161円台後半から**159円台へ反転（1ヶ月で−1.55%の円高）**した。回復し始めたばかりのCPIにとっては、輸入物価経由の向かい風になり得る点が今回の注視材料である。

### 1-2. テイラールール：適正政策金利の試算

```
【テイラールール】
適正金利 ＝ 均衡実質金利 ＋ 目標インフレ率 ＋ 0.5 × 需給ギャップ ＋ 1.5 × インフレギャップ

均衡実質金利（自然利子率）: 0.5%（日銀リサーチ推計レンジ中央値）
目標インフレ率: 2.0%
需給ギャップ: +0.5%
インフレギャップ（コアCPI − 2%）: 1.6% − 2.0% ＝ −0.4%

適正金利 ＝ 0.5 ＋ 2.0 ＋ 0.5 × 0.5 ＋ 1.5 × (−0.4)
         ＝ 0.5 ＋ 2.0 ＋ 0.25 − 0.6
         ＝ 2.15%
```

| 項目 | 値 |
|------|---|
| テイラールール適正金利 | **2.15%**（前回 1.85%） |
| 現在の政策金利 | 0.978%（前回 0.841%） |
| 乖離（過剰緩和幅） | **−1.17%pt**（前回 −1.01%pt） |

**今回の特徴は「利上げしたのに乖離が拡大した」点にある**。政策金利を0.137%ポイント引き上げた一方、コアCPIの反発（1.4%→1.6%）によりインフレギャップが−0.6%から−0.4%へ縮小し、適正金利が0.3%ポイント切り上がったためである。ルールベースで見れば、物価が目標に近づくほど追いかけるべき金利水準も上がる関係にあり、**追加利上げの余地はむしろ広がった**と読める。

#### ⑤ 政策金利・実質金利・自然利子率（金融ブロック）

![政策金利・実質金利（金融ブロック）](./images/policy_rate_chart.png)

日銀は7月も追加利上げを実施し、政策金利は0.841%から**0.978%**へ。2025年12月（0.557%）→2026年6月（0.841%）→7月（0.978%）と、**直近7ヶ月で0.42%ポイントの引き上げ**となり、正常化のペースが明確に加速している。

```
実質金利 ＝ 政策金利（0.978%）− BEI（1.952%）＝ −0.97%
自然利子率（中立基準）＝ 0.5%
緩和超過幅 ＝ −0.97% − 0.5% ＝ −1.47%ポイント
```

実質金利は前回の−1.45%（6月時点）→−1.13%（前回レポート）→**−0.97%** と縮小を続け、**−1%台を脱した**。前回はBEIの低下が縮小の主因だったのに対し、**今回はBEIがほぼ横ばい（−0.02%pt）のなか名目金利の引き上げ（+0.137%pt）がほぼ全額を説明する**。金融引き締めが実質ベースでも効き始めた形だが、なお自然利子率を約1.5%ポイント下回っており、金融環境は**依然として大幅に緩和的**である。

円高は輸入物価を通じてコアCPIを押し下げる方向に働く。ようやく1.6%へ反発したばかりのCPIにとっては向かい風であり、**「CPIの回復」と「円高の進行」が綱引きになる**のが今後1〜2ヶ月の構図となる。

## 3. 総合考察（金融政策への含意）

### 3-1. 現状の総括：反転した収斂と、拡大した乖離

**乖離①：コアCPI（1.6%）とBEI（1.95%）の差 → 0.35%ポイント（前回0.57%ptから縮小）**

前回は「BEIがCPI側へ落ちる」悲観的な収斂だったが、今回は「CPIがBEI側へ近づく」形に反転した。前回懸念した「市場の楽観が過剰」というリスクシナリオは、BEIの下げ止まりによって当面回避されたと判断できる。

**乖離②：テイラールール適正金利（2.15%）と政策金利（0.98%）の差 → 1.17%ポイント（前回1.01%ptから拡大）**

2ヶ月連続の利上げにもかかわらず乖離は拡大した。物価が目標に近づいた分だけ適正金利も上がるためで、**ルールベースの利上げ余地は縮まるどころか広がっている**。この点は日銀の正常化継続を支持する材料である。

### 3-2. 次回MPMに向けたシナリオ分析

**シナリオA：利上げ継続（確率: 中〜高）**

コアCPIの反発、BEIの下げ止まり、需給ギャップ+0.5%、テイラールール乖離の拡大と、材料はいずれも追加利上げを支持する。6月・7月と連続で引き上げた実績もあり、**前回レポート時点（低〜中）から確率は上昇した**。政策金利が1%の大台に乗るかが焦点。

**シナリオB：様子見（確率: 中）**

2ヶ月連続で利上げした直後であり、効果の見極め期間を置く判断。加えて円高への転換がCPIの回復を鈍らせる可能性があり、7月分・8月分のCPIを確認してから動くという選択肢は依然として有力。

**シナリオC：利上げ停止・緩和方向の点検（確率: 低）**

BEIが下げ止まりCPIも反発した以上、正常化路線を止める根拠は乏しくなった。**前回レポート時点（低〜中）から確率は低下した**。円高が急速に進み輸入物価が下落してCPIが再び1.4%を割り込む、といった条件が重ならない限り現実味は薄い。

### 3-3. リスクシナリオ

**上振れリスク（物価加速・利上げ前倒し）**

- 7月分以降のコアCPIが1.8〜2.0%へ続伸 → 目標到達が視野に
- BEIが2%台を回復 → 期待インフレの定着を確認
- 日経225が72,000円台を再び突破 → 資産効果・賃上げ機運の後押し
- → 日銀は追加利上げを継続し、年内に政策金利が1.25%へ接近する可能性

**下振れリスク（円高・物価回復の腰折れ）**

- 円高が157円台を割り込んで進行 → 輸入物価下落でCPI反発が腰折れ
- 6月分の1.6%が一時的な反発にとどまり、7月分で再び1.4%台へ
- BEIが再度1.9%を割り込む
- 米金利低下観測の強まり → 日米金利差縮小 → 円高圧力の加速
- → 日銀は連続利上げをいったん停止し、正常化ペースの再検討を迫られる

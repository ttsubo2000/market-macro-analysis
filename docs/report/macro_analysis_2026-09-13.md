## エグゼクティブサマリー

**前回レポート（2026-08-12）で挙げた3つのウォッチポイントが、そろって決着した回である**。①コアCPIは2026年7月分が**1.8%**となり、6月の1.6%から2ヶ月連続の上昇。②為替は159円台から**153円台へ急速な円高**が進み、前回「割り込むと向かい風」と指摘した157円台をあっさり突破した。③BEI（期待インフレ率）は8月後半（8/18〜8/31）の平均が**1.993%**と、7月後半の1.943%から回復して2%目前に戻した。

その結果、前回まで最大の論点だった「コアCPIとBEIの乖離」は0.35%ポイントから**0.17%ポイント**へ縮小し、ほぼ解消した。実績（CPI）と期待（BEI）が2%近傍で揃いつつある。加えて需給ギャップは**2026年Q2分が新たに公表され+0.7%**（Q1 +0.5%から改善）となり、3ヶ月間続いた「Q1据え置き」状態が解消した。

一方で日銀は**8月に利上げを見送った**（政策金利0.978%→0.977%で実質据え置き）。6月・7月の連続利上げのあとの一服である。物価も需給も改善したのに金利を止めたため、テイラールールが示す適正金利との乖離は1.17%ポイントから**1.57%ポイント**へさらに拡大した。

そして今回の最大の異変は為替である。米10年債利回りが4.68%→**4.98%**へ上昇し、**日米金利差はむしろ3.71%ポイントから4.00%ポイントへ拡大した。にもかかわらず円は3.6%も買われた**。金利差では説明できない円高が起きており、同時に日経225は1ヶ月で**−6.3%**下落している。

### 1-2. テイラールール：適正政策金利の試算

```
【テイラールール】
適正金利 ＝ 均衡実質金利 ＋ 目標インフレ率 ＋ 0.5 × 需給ギャップ ＋ 1.5 × インフレギャップ

均衡実質金利（自然利子率）: 0.5%（日銀リサーチ推計レンジ中央値）
目標インフレ率: 2.0%
需給ギャップ: +0.7%
インフレギャップ（コアCPI − 2%）: 1.8% − 2.0% ＝ −0.2%

適正金利 ＝ 0.5 ＋ 2.0 ＋ 0.5 × 0.7 ＋ 1.5 × (−0.2)
         ＝ 0.5 ＋ 2.0 ＋ 0.35 − 0.3
         ＝ 2.55%
```

| 項目 | 値 |
|------|---|
| テイラールール適正金利 | **2.55%**（前回 2.15%） |
| 現在の政策金利 | 0.977%（前回 0.978%） |
| 乖離（過剰緩和幅） | **−1.57%pt**（前回 −1.17%pt） |

適正金利が0.4%ポイントも切り上がった要因は2つある。**コアCPIの上昇（1.6%→1.8%）でインフレギャップが−0.4%から−0.2%へ縮小し（+0.3%pt寄与）、需給ギャップの改善（+0.5%→+0.7%）が加わった（+0.1%pt寄与）**。前回は「利上げしたのに乖離が拡大した」局面だったが、今回は**利上げを止めた上に適正水準が上がった**ため、乖離の拡大幅（0.40%pt）は前回（0.16%pt）の2倍以上になっている。

ルールベースで見る限り、**現在の政策金利は適正水準の4割弱の高さにとどまっており、正常化はまだ道半ばである**。

### 1-3. 指標別詳細考察

#### ① 需給ギャップ（経済ブロック）

![需給ギャップ（GDPギャップ）](./images/gdp_gap_chart.png)

**3ヶ月間待たれていた2026年Q2分がついに公表され、+0.7%となった**。2025年Q3 +0.1% → Q4 +0.2% → 2026年Q1 +0.5% → Q2 +0.7% と4四半期連続の改善で、需要超過の幅は着実に拡大している。前回レポートで「Q2分は円高転換後の実体経済を映す最初の指標になる」と指摘したが、**結果は改善であり、少なくともQ2までの段階では円高・株価一服の悪影響は実体経済に及んでいない**。

需給ギャップがプラス圏で拡大することは、需要側から物価を押し上げる力が働いていることを意味する。テイラールール上も適正金利を押し上げる方向に効く。ただし**Q2は4〜6月であり、9月の急激な円高・株安はまだ反映されていない**点は前回同様に割り引いて読む必要がある。

---

#### ② コアCPI・物価上昇率（物価ブロック）

![コアCPI（生鮮食品を除く総合・前年比）](./images/cpi_chart.png)

2026年7月分は**1.8%**。4月・5月に1.4%まで沈んだあと、6月1.6%→7月1.8%と2ヶ月連続で持ち直し、**目標2%まで残り0.2%ポイント**に迫った。1年前（2025年7月）の3.1%からは大きく減速しているが、直近の底（1.4%）からは0.4%ポイント戻している。

重要なのは、**この1.8%が「円安期の物価」であるという点**である。輸入物価が消費者物価に波及するには一般に3〜6ヶ月かかるため、7月分のCPIが映しているのは主に春〜初夏の160円前後の為替水準である。**9月に進んだ153円台の円高は、まだこの数字に入っていない**。回復基調が続くかどうかは、円高の押し下げ圧力とそれ以外の押し上げ要因（需給ギャップの拡大・賃金）の綱引き次第となる。

---

#### ③ BEI（期待インフレ率）と④ インフレギャップ（物価ブロック）

![BEI（ブレーク・イーブン・インフレ率）](./images/expected_inflation_chart.png)

BEI は債券市場が織り込む予想インフレ率で、普通国債と物価連動国債の利回り差から算出される。**取得できている範囲では7月17日の1.883%が直近の底で、そこから切り返し、8月後半は1.97〜2.01%のレンジで推移した**。

| 月 | 取得できた期間 | 期間平均 | 期間レンジ |
|----|--------------|---------|-----------|
| 2026-05 | 05-18 〜 05-29（10営業日） | 2.253% | 2.172 〜 2.277% |
| 2026-06 | 06-17 〜 06-30（10営業日） | 2.042% | 1.950 〜 2.088% |
| 2026-07 | 07-17 〜 07-31（10営業日） | 1.943% | 1.883 〜 1.976% |
| **2026-08** | **08-18 〜 08-31（10営業日）** | **1.993%** | **1.969 〜 2.014%** |

> **データ制約**: 取得元（stock-marketdata.com）の表は常に最新10営業日分しか掲載していないため、各月とも**月後半の10営業日のみ**が蓄積されている（月前半の11〜13営業日は欠測）。上表は「月中平均」ではなく**月後半10営業日の平均**である。

3ヶ月続いた低下が止まり、**7月を底に反転した**ことが確認できる。前回レポートで挙げたウォッチポイント③「BEIの2%回復可否」は、8月後半平均1.993%・期間高値2.014%と**ほぼ達成**と評価してよい。市場が「日銀は2%を実現できる」と再び見なし始めた形である。

なお、データソースの都合で**最新値は2026-08-31時点であり、9月に入ってからの円高・株安局面の BEI はまだ反映されていない**。次回更新時にこの局面で期待インフレが崩れなかったかを確認したい。

![インフレギャップ（コアCPI − 物価安定目標 2%）](./images/inflation_gap_chart.png)

インフレギャップ（コアCPI − 2%）は**−0.2%ポイント**。2026年2月にマイナス転落してから6ヶ月連続でマイナス圏だが、4〜5月の−0.6%を底に縮小が続いている。ゼロ復帰（＝目標達成）まであと一歩の距離である。

**CPIとBEIの乖離**も改めて整理する。

| 時点 | コアCPI | BEI | 乖離 | 性格 |
|------|---------|-----|------|------|
| 前々回（2026-06-13） | 1.4% | 1.973% | 0.57%pt | 期待が実績を大きく上回る |
| 前回（2026-08-12） | 1.6% | 1.952% | 0.35%pt | CPIの回復で縮小 |
| **今回（2026-09-13）** | **1.8%** | **1.969%** | **0.17%pt** | **実績が期待に追いつき、ほぼ一致** |

3ヶ月かけて乖離が0.57→0.17%ポイントへ縮小し、しかもその過程は一貫して**「CPIが上に追いついた」**方向だった。期待の方が崩れて収斂する悲観シナリオは回避されたと判断できる。

#### ⑤ 政策金利・実質金利・自然利子率（金融ブロック）

![政策金利・実質金利（金融ブロック）](./images/policy_rate_chart.png)

**8月の政策金利（無担保コールレート翌日物・月平均）は0.977%と、7月の0.978%から実質横ばい**。6月（0.841%）・7月（0.978%）の2ヶ月連続利上げのあと、8月は動かなかった。1年前（2025年8月 0.477%）比では+0.50%ポイントで、この1年で金利水準は2倍になっている。

実質金利（政策金利 − BEI）は**−0.99%**。前回の−0.97%からわずかに緩和方向へ戻った。名目金利を止めた一方でBEIが上がったためで、**据え置きは「現状維持」ではなく、実質ベースでは緩和の再拡大を意味する**。自然利子率0.5%を中立基準とすれば、実質金利は依然として中立から約1.5%ポイント下方にあり、金融環境は明確に緩和的である。

## 2. 外部要因・市場動向

### 2-1. 為替（USDJPY）

| 期間 | 水準 |
|------|------|
| 現在（2026-09-11 終値） | **153.55 円/ドル** |
| 1ヶ月前（2026-08-13） | 159.33 円/ドル |
| 3ヶ月前（2026-06-12） | 160.13 円/ドル |
| 3ヶ月高値 | 163.86 円/ドル（2026-07-29） |
| 3ヶ月安値 | 153.48 円/ドル（2026-09-09） |
| 1ヶ月変化率 | **−3.62%（円高方向）** |
| 3ヶ月変化率 | **−4.11%（円高方向）** |

**前回レポートで「今回新たに浮上した最大の向かい風」と位置づけた円高が、想定より速く進んだ**。7月29日に3ヶ月高値の163.86円を付けてから、わずか6週間で10円超の円高となり、9月9日に153.48円の3ヶ月安値を更新した。前回「157.53円を割り込むと輸入物価経由でCPI回復を打ち消す」と書いた水準は、9月4日（155.66円）の時点で既に突破されている。

とくに9月に入ってからの動きが急で、9月3日の158.92円から9月9日の153.48円まで、**4営業日で5.4円（3.4%）の円高**が進んだ。

**日米金利差との関係**：

| 指標 | 値 |
|------|---|
| 米10年債利回り（2026-09-11） | 4.975%（前回 4.684%） |
| 日本政策金利 | 0.977%（前回 0.978%） |
| 日米金利差 | **4.00%ポイント**（前回 3.71%pt） |

**今回最も説明の難しい現象がここにある**。米金利が4.68%→4.98%へ上昇（3ヶ月安値4.37%からは0.6%ポイント上昇）し、日本は据え置いたため、金利差は3.71%ポイントから4.00%ポイントへ**拡大**した。教科書的には金利差の拡大はドル買い・円売り要因であり、円安に働くはずである。**それにもかかわらず円は3.6%買われた**。

金利差で説明できない円買いの候補としては、(a) 日銀の追加利上げ・正常化加速への期待が先行して織り込まれた、(b) 世界的なリスクオフで安全資産としての円が買われた、(c) 円キャリー取引（低金利の円で調達して高金利通貨に投資する取引）の巻き戻し、といった要因が考えられる。**同時期に日経225が−6.3%下落していることは (b)(c) と整合的**であり、金利差要因より資金フロー要因が優勢になっている可能性が高い。

|------|------|
| 現在（2026-09-11 終値） | **64,011 円** |
| 1ヶ月前（2026-08-13） | 68,309 円 |
| 3ヶ月前（2026-06-12） | 66,020 円 |
| 3ヶ月高値 | 72,366 円（2026-06-25） |
| 3ヶ月安値 | 61,434 円（2026-07-29） |
| 1ヶ月変化率 | **−6.29%（下落）** |
| 3ヶ月変化率 | **−3.04%（下落）** |

**前回「高値圏でのもみ合い」と評した株式市場は、明確な下落局面に転じた**。1ヶ月で−6.29%、3ヶ月変化率も前回の+7.77%からマイナス圏（−3.04%）へ反転している。6月25日に付けた72,366円の3ヶ月高値からは約12%の下落である。

注目すべきは**円高と株安が同時に進行している**点である。前回レポートで「これまでの株高が円安に相当程度支えられていた」と指摘したが、その関係が逆回転を始めた形といえる。輸出企業の採算悪化見通しに加え、円キャリーの巻き戻しが株式からの資金流出を伴っているとすれば、円高と株安は同じ資金フローの表と裏ということになる。

金融政策への含意は両義的である。株安による資産効果の剥落・企業マインドの悪化は利上げを慎重にさせる方向に働く一方、**株価は日銀の物価判断の直接の材料ではない**。あくまで円高を通じた物価への波及が本筋である。

## 3. 総合考察（金融政策への含意）

### 3-1. 現状の総括：国内は追い風、外部は逆風

**国内指標（3つとも利上げ支持）**

| 指標 | 方向 | 政策含意 |
|------|------|---------|
| コアCPI 1.8%（2ヶ月連続上昇） | 改善 | 目標接近 → 利上げ支持 |
| 需給ギャップ +0.7%（4四半期連続改善） | 改善 | 需要超過拡大 → 利上げ支持 |
| BEI 8月後半平均1.993%（7月を底に反転） | 改善 | 期待インフレ定着 → 利上げ支持 |

**外部環境（利上げに慎重を促す）**

| 要因 | 方向 | 政策含意 |
|------|------|---------|
| 円高 153円（1ヶ月 −3.6%） | 急変 | 輸入物価下落 → 数ヶ月後のCPIを押し下げ |
| 日経225 64,011円（1ヶ月 −6.3%） | 下落 | 資産効果剥落・マインド悪化 |
| 日米金利差 4.00%pt（拡大） | 拡大 | 金利差で説明できない円買いの継続リスク |

**乖離①：コアCPI（1.8%）とBEI（1.97%）の差 → 0.17%ポイント（前回0.35%ptから縮小・ほぼ解消）**

3ヶ月かけて実績が期待に追いついた。物価の現状認識としては最も健全な形であり、**日銀が「2%の持続的・安定的な実現」を宣言しやすい地合いが整いつつある**。

**乖離②：テイラールール適正金利（2.55%）と政策金利（0.98%）の差 → 1.57%ポイント（前回1.17%ptから拡大）**

3ヶ月連続で乖離が拡大している（1.01 → 1.17 → 1.57%pt）。今回は利上げを止めた分だけ拡大ペースが加速した。**ルール上の利上げ余地は過去3回のレポートで最大**である。

**論点は「国内指標が示す利上げ余地」と「9月に急変した外部環境」のどちらを重く見るかに集約される。**

### 3-2. 次回MPMに向けたシナリオ分析

**シナリオA：利上げ再開（確率: 中〜高）**

国内3指標がそろって改善し、テイラールール乖離も1.57%ポイントまで開いた。8月の据え置きが「2ヶ月連続利上げ後の一回休み」であったなら、材料が整った今回は再開の条件を満たす。政策金利1%台乗せが焦点となる。**前回（中〜高）から確率は維持**。

**シナリオB：様子見継続（確率: 中）**

9月に入ってからの円高（−3.6%）・株安（−6.3%）は速度が急であり、その影響を見極めたいという判断は自然である。円高は数ヶ月遅れてCPIを押し下げるため、**「今のCPI 1.8%は過去の円安の産物であり、これから下がる」と読めば、ここでの利上げは後で行き過ぎになる**。8月に一度止めた慣性も働く。**前回（中）から確率はやや上昇**。

**シナリオC：利上げ停止・緩和方向の点検（確率: 低）**

BEIが2%近傍を回復し需給ギャップも拡大している以上、正常化路線そのものを止める根拠は乏しい。株安が金融システム不安に発展する、円高が140円台まで一気に進む、といった急変が重ならない限り現実味は薄い。**前回（低）から変化なし**。

### 3-3. リスクシナリオ

**上振れリスク（物価加速・利上げ前倒し）**

- 8月分以降のコアCPIが2.0%へ到達 → 目標達成が視野に
- BEIが9月も2%台を維持 → 期待インフレの定着を確認
- 需給ギャップがQ3もプラス幅を拡大
- → 日銀は利上げを再開し、年内に政策金利が1.25%へ接近する可能性

**下振れリスク（円高による物価回復の腰折れ）**

- 円高が150円を割り込んで進行 → 輸入物価下落が本格化
- 3〜6ヶ月後（2026年末〜2027年初）のコアCPIが再び1.4%台へ失速
- 株安の継続で企業の賃上げ・設備投資マインドが後退
- 円キャリー巻き戻しが加速 → 為替・株式のボラティリティ上昇
- → 日銀は据え置きを継続し、正常化ペースの再検討を迫られる

## 4. まとめ：3つのウォッチポイント

| 1 | **円高のCPIへの波及タイミング** | 153円台の影響は3〜6ヶ月遅れで出る。8〜10月分のコアCPIが1.8%を維持できるかが、円高の押し下げ圧力の強さを測る最初の材料 |

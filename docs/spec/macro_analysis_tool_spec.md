# 日銀マクロ経済モニタリング＆予測ツール 仕様書

> 参考資料：日本銀行副総裁 氷見野良三「最近の金融経済情勢と金融政策運営」（2026年3月2日）

---

## 1. 概要

### 1.1 目的

日本銀行が金融政策判断に用いる「マクロ経済の見取り図」フレームワークに基づき、現状の経済・物価・金融の状態をリアルタイムで可視化し、将来の政策金利パスを予測・シミュレーションできるWebツールを構築する。

### 1.2 想定ユーザー

- 日本株投資家（特に金利感応度の高いセクター：半導体・銀行・不動産）
- マクロ経済に関心のある個人投資家・研究者
- 金融政策の動向をウォッチするアナリスト

### 1.3 技術スタック（推奨）

| 層 | 技術候補 |
|---|---|
| フロントエンド | React + Recharts / D3.js |
| データ取得 | yfinance（Python）、日銀時系列統計DB API、内閣府API |
| バックエンド | FastAPI（Python） |
| 予測モデル | scikit-learn / statsmodels（VAR, ARIMA） |
| ホスティング | Streamlit Cloud / Vercel + Railway |

---

## 2. フレームワーク定義

本ツールは日銀の「マクロ経済の見取り図」を3ブロック構造で実装する。

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│   金融ブロック    │────▶│   経済ブロック    │────▶│   物価ブロック   │
│                 │◀────│                  │◀────│                 │
└─────────────────┘     └──────────────────┘     └─────────────────┘
```

### 2.1 金融ブロック

| 変数 | 定義 | データソース |
|---|---|---|
| 政策金利 | 無担保コールレート（翌日物）誘導目標 | 日銀時系列統計DB |
| 予想インフレ率 | BEI（ブレーク・イーブン・インフレ率）、短観物価見通し | 日銀、Bloomberg |
| 実質金利 | 政策金利 − 予想インフレ率 | 算出値 |
| 自然利子率 | 推計値（Laubach-Williams法相当） | 日銀リサーチ論文ベース |
| 金融環境指数 | 貸出態度DI・社債スプレッド・株価の合成指数 | 日銀短観、Bloomberg |

**緩和度合いスコア：** `実質金利 − 自然利子率` の符号・大きさで緩和/引き締めを判定

### 2.2 経済ブロック

| 変数 | 定義 | データソース |
|---|---|---|
| 実質GDP成長率 | 前期比年率、前年比 | 内閣府GDP統計 |
| 潜在GDP成長率 | HP フィルター / 日銀推計 | 内閣府、日銀 |
| GDPギャップ | 実質GDP − 潜在GDP（対潜在GDP比） | 内閣府 |
| 短観加重平均DI | 設備判断DI＋雇用判断DIの加重平均（符号反転） | 日銀短観 |
| 消費者態度指数 | 内閣府消費動向調査（季節調整済） | 内閣府 |

### 2.3 物価ブロック

| 変数 | 定義 | データソース |
|---|---|---|
| CPI（除く生鮮食品） | 前年比 | 総務省 |
| 刈込平均インフレ率 | 上下各10%品目を除いた平均 | 日銀 |
| トレンドインフレ率 | Trend-Cycle BVAR推計値 | 日銀リサーチ |
| 名目賃金上昇率 | 所定内給与前年比（一般・パート） | 厚生労働省 |
| 予想インフレ率（各主体別） | 家計・企業・エコノミスト・市場 | 日銀、QUICK、JCER |

## 3. 機能仕様

### 3.1 ダッシュボード（現状モニタリング）

#### 3.1.1 マクロ見取り図パネル

- 3ブロック（金融・経済・物価）をインタラクティブな図として表示
- 各ブロックの主要指標を「信号機カラー」で現状評価
  - 🟢 緑：目標に向けて良好
  - 🟡 黄：要注意・不確実
  - 🔴 赤：目標から乖離・リスク高

#### 3.1.2 時系列チャート群

- GDPギャップの推移（1990年〜現在）
- CPI（除く生鮮）・刈込平均・トレンドインフレ率の3系列重ね描き
- 政策金利・実質金利・自然利子率の推移（緩和ゾーン塗りつぶし）
- 名目賃金・予想インフレ率の推移

#### 3.1.3 現状サマリーカード

最新データを自動取得し、以下を一枚のカードに表示：

```
政策金利：0.50%  ▲（前回比 +0.25%）
実質金利：▲▲▲ きわめて低い（緩和的）
GDPギャップ：+0.1%（ほぼゼロ近傍）
コアCPI：+2.5%（目標超過中）
賃金上昇率：+3.1%（好循環継続）
```

---

### 3.2 シナリオ予測エンジン

#### 3.2.1 シナリオ設定パラメータ

ユーザーが以下をスライダー・ドロップダウンで設定：

| パラメータ | 範囲 | デフォルト |
|---|---|---|
| 海外経済成長率（米国） | -2% 〜 +4% | +2.0% |
| 原油・エネルギー価格変動率 | -30% 〜 +50% | 0% |
| 政府の物価高対策（継続/終了） | ON/OFF | ON |
| 米国関税政策の影響度 | 軽微/中程度/深刻 | 中程度 |
| 国内賃上げ率（来春闘） | 2% 〜 6% | 3.5% |

#### 3.2.2 シナリオプリセット

| シナリオ名 | 説明 |
|---|---|
| 🟢 **ベースライン** | 日銀2026年1月展望レポートの基本シナリオ |
| 🔵 **楽観シナリオ** | 賃上げ加速・海外経済好調・物価安定 |
| 🔴 **リスクシナリオ** | 米国景気後退・円高・物価下振れ |
| 🟠 **スタグフレーション** | 供給ショック継続・需要低迷 |

#### 3.2.3 予測出力（12〜24ヶ月先）

- 政策金利パス予測（信頼区間付き）
- CPI・GDPギャップの予測推移グラフ
- 「次の利上げ」タイミングの確率分布
- 最終到達金利（ターミナルレート）の分布

---

### 3.3 日銀政策判断チェッカー

日銀の判断ロジックを再現するルールベース判定モジュール。

```
IF GDPギャップ > 0
AND トレンドインフレ率 > 1.5%
AND 予想インフレ率（企業・家計） > 1.5%
AND 賃金上昇率 > 3%
AND 実質金利 < 自然利子率
THEN → 「利上げ余地あり」判定
```

各条件の充足状況をチェックリスト形式で可視化し、利上げ確度を0〜100%のスコアで表示。

---

### 3.4 日本株スクリーニング連携（オプション）

政策金利予測に基づき、影響を受けやすい銘柄セクターをハイライト：

| 金利上昇時 | 影響 |
|---|---|
| 銀行・保険 | ポジティブ（利ザヤ拡大） |
| 不動産REIT | ネガティブ（調達コスト増） |
| 半導体・設備投資関連 | 中立〜ネガティブ（円高進行リスク） |
| 内需・消費 | ネガティブ（可処分所得低下） |

## 4. データ取得仕様

### 4.1 自動更新スケジュール

| データ | 更新頻度 | 取得元API |
|---|---|---|
| 政策金利・短観 | 四半期 | 日銀時系列統計DB（JSON API） |
| CPI | 月次 | 総務省e-Stat API |
| GDP・GDPギャップ | 四半期 | 内閣府GDP速報 |
| BEI・社債スプレッド | 日次 | yfinance / Bloomberg API |
| 名目賃金 | 月次 | 厚生労働省毎月勤労統計 |

### 4.2 日銀時系列統計DB APIエンドポイント例

```python
import requests

# 無担保コールレート（翌日物）
url = "https://www.stat-search.boj.or.jp/ssi/mtshtml/fm02_m_1.html"

# 短観（貸出態度判断DI）
url = "https://www.stat-search.boj.or.jp/ssi/mtshtml/bq01_q_4.html"
```

※ 日銀統計データはWebスクレイピングまたは公開CSVの定期取得で対応。

## 5. UI/UX 設計方針

### 5.1 レイアウト構成

```
┌─────────────────────────────────────────────┐
│  ヘッダー：最終データ更新日時・日銀MPM次回予定  │
├───────────────┬─────────────────────────────┤
│               │                             │
│  見取り図      │     メインチャートエリア      │
│  （3ブロック）  │  （タブ切替：金融/経済/物価） │
│               │                             │
├───────────────┴─────────────────────────────┤
│  シナリオ設定パネル（スライダー群）            │
├─────────────────────────────────────────────┤
│  予測グラフ（政策金利パス・CPI・GDPギャップ）  │
└─────────────────────────────────────────────┘
```

### 5.2 インタラクション要件

- シナリオパラメータ変更 → リアルタイムでグラフ更新（デバウンス 300ms）
- チャートはホバーでツールチップ表示（数値・日付・出典）
- 各指標に「？」アイコン → 用語解説ポップアップ
- スマートフォン対応（iPad縦向き動作を特に考慮）
